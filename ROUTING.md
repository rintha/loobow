# Page URLs and FileZilla uploads

| Public URL | File |
| --- | --- |
| `https://loobow.com/` | `index.html` |
| `https://loobow.com/mosaic.html` | `mosaic.html` |
| `https://loobow.com/digital.html` | `digital.html` |

The homepage panels and division switches link directly to the HTML files. Canonical links, social metadata, structured data and the sitemap use these same public URLs. No React conversion, clean-URL rewrite rules or Nginx changes are required. The `.html` extension stays visible in the browser address bar.

## Upload this navigation update

Overwrite these files in the existing website document root using FileZilla:

- `index.html`
- `mosaic.html`
- `digital.html`
- `js/welcome.js` (inside the existing `js` folder)
- `sitemap.xml`
- `css/welcome.css` if the latest larger homepage titles have not yet been uploaded

Keep the existing `css`, `js`, `images`, `fonts` and `public` folders alongside the HTML files. The asset paths are unchanged. `robots.txt` continues to point to the same sitemap file.

The optional `.htaccess` and `web.config` files now redirect old clean division URLs to the HTML pages on compatible Apache/IIS servers. If those earlier configuration files were already active on a compatible host, upload the updated versions too so they no longer redirect HTML pages back to clean URLs. Nginx ignores these files; the live Nginx host does not need them for direct HTML navigation. The previously proposed Nginx snippet has been retired and should not be applied.

The live check on 31 October 2026 found HTTP 200 for `/mosaic.html` and `/digital.html`, and Nginx HTTP 404 responses for `/mosaic` and `/digital`. Switching navigation to the existing HTML files avoids those missing routes. Existing links from outside the website to `/mosaic` or `/digital` still need server routing if they are to work; this change fixes navigation generated by this site.

## Bookmarks and local preview

Older homepage section bookmarks such as `/?source=bookmark#work` are forwarded by `js/welcome.js` to `/digital.html?source=bookmark#work`. Normal section links within each division retain their existing fragments.

VS Code Live Server can serve the pages directly without custom mount settings. Restart Live Server after the settings change. Test the homepage, both division links, the Home icon and the switch between Mosaic and Digital. Refresh each HTML page directly and check that images, downloads and section navigation still work. On the hosted site, hard-refresh after uploading to pick up updated files.
